Abstract

The Student Management App is a Flutter-based mobile application developed to manage student information in a simple and efficient way. The application allows users to add, view, edit, search, and delete student details such as student name, roll number, department, year, and phone number.

The main purpose of this project is to reduce manual work involved in maintaining student records and provide an easy-to-use digital solution. The application uses Flutter widgets to create a simple and responsive user interface. It demonstrates important Flutter concepts such as navigation, forms, text fields, lists, buttons, and state management.

This project is designed as a beginner-friendly application and can be further enhanced by adding features such as Firebase/SQLite database, authentication, attendance management, marks management, and notifications.
